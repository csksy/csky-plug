# csky-plug

CloudStream3 extensions repository.

## Plugins

| Plugin | Description |
|---|---|
| KMMovies | Movies & TV Series from kmmovies.online — all episodes per season, every quality (480p–4K), multi-audio sources (direct Google streams + Google Drive) |
| TelegramEera | Search & stream Movies / TV / Anime from Telegram (Search Zone group + MovieEera bot) through the Eera bridge (see /bridge) |
| RaghavAnime | Aggregated anime providers (SUB/DUB) |

The plugin list is generated automatically by the build workflow (plugins.json).
